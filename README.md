# Облік — трекер особистих витрат

Відкрийте `index.html` у браузері. Сторінка працює без встановлення пакетів, збирання та запуску сервера. Щоб перейти до другого завдання, натисніть «Реєстрація».

| Завдання | Що реалізовано |
| --- | --- |
| 1. Трекер витрат | Додавання й видалення витрат, перевірка назви та додатної суми, автоматичний підрахунок загальних витрат. Суми вводяться у гривнях і обчислюються в цілих копійках. |
| 2. Реєстрація | JavaScript перевіряє довжину імені (від 3 символів), формат email, довжину пароля (від 8 символів), збіг паролів і згоду з умовами. Помилки з’являються під відповідними полями. Після успішної перевірки сторінка показує «Реєстрація успішна!». |
| 3. Статистика витрат | На сторінці трекера є сума для кожної категорії, фільтр за категорією, пошук за назвою під час введення й очищення всього журналу з підтвердженням. Підсумки завжди враховують усі записи. |

Витрати, вибрана категорія фільтра та пошуковий запит зберігаються у `localStorage` браузера. Форма реєстрації перевіряє введені дані лише в поточній вкладці. Після успіху вона очищає поля.

Сторінки написані на HTML, CSS і JavaScript.
